Projeto desenvolvido para gerenciar o banco de dados para controle de matrículas de alunos.

Sistema foi criado ultilizando SQL Server.

Objetivo - Praticar Modelagem de Dados, Consultas SQL, Tiggers, Procedures e Automação no Banco de Dados.

Banco de Dados Relacional

Criação do Banco de Dados - Ficha de Matriculas.

Criação de Tabelas de Alunos - Responsável - Endereço - Telefone - Professores - Histórico de Turma - Histórico Pagamento.

Criação de View.

Criação de Procedures Insert - Update - Delete - Backup e Restore.

Criação Triggers de Históricos.

Job - Backup Automatico com Dia e Hora agendado.
